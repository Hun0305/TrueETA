## 2. 카카오맵과 괴리 — **데이터 대기 중**

> 카카오맵에서 뜨는거랑 괴리가 심함. (이건 1번의 연장선일지도)

원인은 파악됐다. **화면 보간이 낙관적이다.**

화면은 ETA 를 초당 1초씩 깎는데, 실제 감소율은 0.6~0.8 이다.
정차·신호 때문에 시계보다 느리게 줄어든다.
10분 주기일 때 6분 경과 시점에 카카오맵보다 2분 빨랐다 — 비율 약 0.67.

주기가 길수록 이 편향이 쌓인다. 피크를 2분으로 줄인 것이 1차 완화다.

## 3. 회차대기 판정 — 구현 완료

> 회차지연 대기로 인해서 정보가 없으면 아예 회색으로뜸. 이 알고리즘 구현해야함

전문은 **[judge-algorithm.md](judge-algorithm.md)**.

시간표와 대조하려 했으나 GBIS·TAGO 어디에도 없었다 — 마을버스는 정시 운행이
아니라 배차간격 운행이라 그 데이터가 생성되지 않는다. 대신 신호 셋을 쓴다:
`flag=WAIT`(확정) · **위치**(조회 1회로 아는 즉시 신호) · ETA 감소율.

회차지에 있는 차는 ETA 를 회색으로 죽이고 "회차지 · 더 걸릴 수 있음" 을 병기한다.

- [ ] `stall_ratio`(0.3)·`stall_seconds`(240) 튜닝 — **아직 근거 없는 추정치**
